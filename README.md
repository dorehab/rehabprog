# DoRehab Indonesia — Aplikasi Web Rehabilitasi Cedera Olahraga 4 Fase

Referensi klinis dan edukasi berbasis bukti dalam **Bahasa Indonesia** yang dibangun dengan struktur standar **HTML, CSS, JavaScript, dan JSON**. Mencakup 9 cedera olahraga utama termasuk **Subluksasi Sendi Panggul (Hip Subluxation)**.

## Struktur Folder

```text
DoRehab-Indonesia/
├── index.html          # Halaman utama website
├── css/
│   └── styles.css      # Desain visual Warm Editorial & Athletic Performance
├── js/
│   └── app.js          # Logika interaktif, generator diagram SVG, dan fallback offline
├── data/
│   └── injuries.json   # Database JSON terstruktur (9 cedera, 3 derajat, 4 fase, 144 latihan)
└── README.md           # Panduan penggunaan dan hosting gratis
```

## Cara Menggunakan & Hosting

### 1. Buka Secara Lokal (Offline)
Klik dua kali file `index.html` untuk membukanya langsung di browser (Chrome, Edge, Safari, Firefox).

### 2. Publikasikan Online Gratis (Netlify Drop)
1. Buka https://app.netlify.com/drop
2. Seret dan lepas (drag & drop) seluruh folder **`DoRehab-Indonesia`** ke jendela browser.
3. Bagikan tautan `https://....netlify.app` yang dihasilkan kepada mahasiswa atau rekan sejawat.
